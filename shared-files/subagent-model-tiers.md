# subagent-model-tiers

Единый словарь тиров мощности и моделей для субагентов.
Каждая модель записана двумя формами через слэш: slug harness / имя модели (параметры). Это обычные строки, не код. Параметры справа совпадают с суффиксом slug: -medium → (effort=medium), -thinking → (thinking=true). Если отдельного параметра нет, справа только имя. Роль субагента задаётся его промптом и не определяет тир. Сначала выбери минимальный достаточный тир по сложности, неоднозначности и риску задачи, затем первую доступную строку модели внутри этого тира.

## Общие правила

1. Для каждого запуска субагента сначала определи минимальный достаточный тир по правилам вызывающего скилла или workflow, затем выбери модель из списка выбранного тира.
2. Модели внутри каждого тира перечислены в порядке приоритета. Всегда выбирай первую доступную строку из списка выбранного тира целиком.
3. Строка доступна, если текущий harness принимает левый slug либо умеет запустить ту же модель по правому имени и параметрам. Суффикс slug и параметры в скобках — одно и то же, не два разных варианта. Если строка недоступна, переходи к следующей по списку в рамках того же тира.
4. Повышай тир только по явному правилу вызывающего скилла или workflow: из-за сложности, риска либо результата предыдущей попытки. Недоступность модели сама по себе не является основанием для повышения.
5. Если ни одна модель выбранного тира недоступна, используй либо **auto** режим, либо текущую **inherit** модель.
6. Не понижай тир, явно заданный вызывающим скиллом или workflow.

## junior

Используй для узких, предсказуемых и низкорисковых задач с явно заданным способом выполнения:

- выполнить локальное механическое изменение по точным инструкциям;
- извлечь факты, собрать список или краткую выжимку;
- разложить данные по уже понятной структуре;
- проверить ограниченный артефакт по явному чеклисту.

Подходящие модели:

1. composer-2.5 / Composer 2.5
2. gpt-6-luna-medium / GPT-6 Luna (effort=medium)
3. claude-haiku-5-5-medium / Claude Haiku 5.5 (effort=medium)
4. gemini-3.8-flash-low / Gemini 3.8 Flash (effort=low)
5. kimi-k2.7-code / Kimi K2.7 Code
6. kimi-k3-low / Kimi K3 (effort=low)

## middle

Используй для основной рабочей нагрузки с умеренной сложностью, неоднозначностью или риском:

- реализовать или проверить изменение, требующее понимания нескольких связанных частей;
- самостоятельно выбрать локальные технические детали;
- проанализировать поведение, риски и регрессии;
- исправить проблемы, найденные предыдущей попыткой.

Подходящие модели:

1. composer-2.5 / Composer 2.5
2. gpt-6.1-sol-medium / GPT-6.1 Sol (effort=medium)
3. claude-sonnet-5-5-high / Claude Sonnet 5.5 (effort=high)
4. gemini-3.1-pro / Gemini 3.1 Pro
5. gemini-3.8-flash-high / Gemini 3.8 Flash (effort=high)
6. glm-5p3-high / GLM 5.3 (effort=high)
7. kimi-k3-high / Kimi K3 (effort=high)

## senior

Используй для сложных, неоднозначных или высокорисковых задач, а также когда менее мощный тир не дал результата:

- провести архитектурный или системный анализ;
- разрешить конфликтующие ограничения и нетривиальные компромиссы;
- работать с конкурентностью или критическими публичными контрактами вне узкого контура `critical`;
- критически проверить сложное решение;
- продолжить работу после неуспешной попытки на `middle`.

Подходящие модели:

1. grok-4.7-high / Grok 4.7 (effort=high)
2. gpt-6.1-sol-high / GPT-6.1 Sol (effort=high)
3. claude-opus-5-5-high / Claude Opus 5.5 (effort=high)
4. kimi-k3-max / Kimi K3 (effort=max)
5. muse-wonder-1.0-high / Muse Wonder 1.0 (effort=high)
6. gemini-4-argon-medium / Gemini 4 Argon (effort=medium)

## critical

Используй только для узкой независимой проверки безопасности отдельным субагентом. Не применяй этот тир к обычным профильным ревью (`requirements`, `correctness`, `performance`, `tests`), общей разработке, verifier или исследованию кода.

- проверить безопасность: границы доверия, аутентификацию, авторизацию, секреты, недоверенный ввод.

Подходящие модели:

1. grok-4.7-xhigh / Grok 4.7 (effort=xhigh)
2. gpt-6-astra-xhigh / GPT-6 Astra (effort=xhigh)
3. claude-fable-5-1-thinking-xhigh / Claude Fable 5.1 (thinking=true, effort=xhigh)
4. gemini-4-argon-high / Gemini 4 Argon (effort=high)

# Временные артефакты

Удаляй **только** файлы из списка ниже. Всё остальное, даже если кажется черновиком, **не** удаляй.

## Список

- `memory-bank/changes/<feature-id>/spec.md`
- `memory-bank/changes/<feature-id>/plan.md`
- путь, который инструкции проекта **явно** называют временным рабочим артефактом

Корень `memory-bank/` бери из уже загруженного контекста агента (`AGENTS.md`, правила проекта). Если корень банка в контексте не виден — ищи только `memory-bank/changes/` в корне репозитория. Не обходи всё дерево в поисках любых `spec.md` / `plan.md`.

## Когда удалять

Файл из списка удаляй, только если **все** условия истинны:

1. путь совпадает со списком;
2. файл уже есть в истории git (отслеживается или есть хотя бы один коммит по этому пути);
3. в инструкциях проекта нет явного запрета удалять этот файл или каталог `changes/`;
4. вызов `/bro-remember-it` уже завершился: знание записано **или** сказано, что писать нечего;
5. у файла нет незакоммиченных правок.

Если у файла из списка есть незакоммиченные правки — **ОСТАНОВИСЬ** и спроси человека. Не выбрасывай несохранённую в git версию.

Если файла нет в git — оставь его. Неудалённое незакоммиченное содержимое иначе потеряется.

## Как удалять

- Удаляй файл из рабочей копии и из индекса (`git rm`), чтобы удаление вошло в коммит закрытия.
- Пустой каталог `changes/<feature-id>/` после удаления файлов не создавай заново и не коммить.
- Не трогай `project/`, `features/`, `playbooks/` и прочий постоянный слой знаний.

# Допуск к финализации

Перед коммитом, `/bro-remember-it`, удалением временных артефактов и пушем реши, можно ли сейчас закрывать задачу.

## Пункты

Сверяй только конкретные пункты:

- `AC-N` из критериев приёмки;
- шаги `Шаг N`.

Бери их из двух источников:

- файлы spec и plan из [списка временных артефактов](./temp-artifacts.md), если они есть;
- текст спеки или плана уже в этом разговоре, включая результат `CreatePlan` и план, записанный в чате.

Другие spec и plan по дереву не ищи. Если пунктов нет — допуск пройден, иди дальше по порядку работы.

## Когда пункт закрыт

Пункт закрыт, если diff показывает его наблюдаемый результат или изменение шага, либо разговор уже показывает, что пункт сделан.

Пункт не закрыт, если этого нет. Сознательно отложенный пункт тоже не закрыт.

Явное расхождение — diff противоречит пункту.

## Стоп

**ОСТАНОВИСЬ**, если есть незакрытый пункт или явное расхождение с diff. Перечисли такие пункты и задай один вопрос:

1) закрыть несмотря на это;
2) не закрывать.

Дальше иди только после ответа 1). Если в этом разговоре человек уже явно выбрал закрыть несмотря на эти же пункты — не спрашивай снова.

Пока допуска нет — не коммить, не вызывай `/bro-remember-it`, не удаляй временные файлы и не пушь.

Не останавливайся из-за общей неуверенности и из-за отсутствия спеки или плана. Не доделывай код и не делай ревью вместо допуска.

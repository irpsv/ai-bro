# CreatePlan

Workflow для режима планирования harness: план оформляется и размещается тулом `CreatePlan` (или аналогом), без записи файла агентом.

## ОБЩИЕ ПРАВИЛА

- **ОБЯЗАТЕЛЬНО** соблюдай [правила диалога](../dialog-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай и **НЕ нарушай** [порядок работы](#порядок-работы)!
- План **ДОЛЖЕН** быть однозначным, без вариаций и вопросов в нём. Все вопросы и вариации **НУЖНО** решать с человеком.
- План **НЕ ДОЛЖЕН** подменять шаги реализации кодом, diff, патчами или псевдокодом.
- Если для описания шага требуется фрагмент реализации, шаг **НУЖНО** переписать на более высокий уровень абстракции.
- При составлении плана **ОБЯЗАТЕЛЬНО** соблюдай структуру разделов из [file-plan-template.md](../templates/file-plan-template.md).
- Разделы со шагами **ОБЯЗАТЕЛЬНО** оформляй по [step-rules.md](../step-rules.md).

## ОГРАНИЧЕНИЯ / STOP

- **ЗАПРЕЩЕНО** создавать или обновлять файлы плана (`plan.md` и любые другие артефакты плана) через запись в репозиторий.
- **ЗАПРЕЩЕНО** спрашивать выбор `inline` / `file` и подтверждение пути размещения.
- **ЗАПРЕЩЕНО** вызывать субагента для ревью, критики или проверки плана.
- **ЗАПРЕЩЕНО** придумывать и додумывать факты или гипотезы. Любая неоднозначность **ДОЛЖНА** быть решена до вызова `CreatePlan`.

## ПОРЯДОК РАБОТЫ

1. **ПРОЧИТАЙ** [file-plan-template.md](../templates/file-plan-template.md) и [step-rules.md](../step-rules.md).
2. Если информации всё ещё недостаточно для однозначного плана — **ЗАПРОСИ** её у человека по [правилам диалога](../dialog-rules.md).
3. **ВЫЗОВИ** `CreatePlan` (или аналог harness для создания плана). Передай полное содержимое плана по структуре шаблона. Если тул принимает заголовок/имя — укажи краткое название задачи. Если тул принимает список todos — отрази в нём шаги реализации в том же порядке, что и в тексте плана. **НЕ ПИШИ** файл плана сам.
4. **ОСТАНОВИСЬ** и жди дальнейших указаний человека (правки плана через harness или переход к реализации).

## Содержание плана

План в `CreatePlan` **ДОЛЖЕН** содержать разделы:

- `Задача и контекст`
- `Целевой результат`
- `Принятые решения`
- `Рамки задачи`
- `Критерии приемки`
- `Шаг 1..N`

Раздел `Принятые решения` **МОЖЕТ** присутствовать только если есть зафиксированные договорённости. Иначе раздел **НЕ** создавай.

# Bro Init Memory Bank

Твоя задача — **первично создать** memory bank проекта: каноническая структура и начальное заполнение контекста.

**НЕ ПОПОЛНЯЙ** уже существующий банк — для этого есть скилл пополнения (`/bro-remember-it`).
**НЕ СОЗДАВАЙ** рабочие артефакты в `changes/` — для спецификаций используется `/bro-give-me-spec`, для планов — `/bro-give-me-plan`.

## ОБЩИЕ ПРАВИЛА

- **ОБЯЗАТЕЛЬНО** соблюдай [правила диалога](./references/dialog-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай [структуру memory bank](./references/memory-bank-structure.md) и [правила содержимого](./references/content-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай и **НЕ нарушай** [порядок работы](#порядок-работы)!
- Сначала самостоятельно собери контекст из репозитория.
- Не спрашивай то, что можно установить с высокой уверенностью.
- Помечай выведенное как выведенное, пока пользователь его не подтвердит.

## ОГРАНИЧЕНИЯ / STOP

- **ЗАПРЕЩЕНО** перезаписывать существующий memory bank.
- **ЗАПРЕЩЕНО** создавать или изменять файлы в `changes/` (кроме пустого каталога при инициализации).
- **ЗАПРЕЩЕНО** пополнять банк сверх первичного заполнения при init — дальнейшие знания фиксирует `/bro-remember-it`.
- **ЗАПРЕЩЕНО** придумывать факты о проекте.

## ПОРЯДОК РАБОТЫ

1. **ПРОВЕРЬ**, что `memory-bank/index.md` отсутствует. Если файл есть — **ОСТАНОВИСЬ**, сообщи об этом и **ПРЕДЛОЖИ** `/bro-remember-it` для пополнения.
2. **ПРОЧИТАЙ** [init-memory-bank](./workflows/init-memory-bank.md) и **СОБЛЮДАЙ** его инструкции.
3. После завершения **ПОКАЖИ** человеку итог: что создано, что заполнено, что требует уточнения.

## Quality Control

Перед завершением проверь:

- структура соответствует схеме memory bank;
- `project/overview.md`, `project/tech-stack.md`, `project/architecture.md` содержат осмысленный черновик или подтверждённые факты;
- `changes/` создан и не заполнен рабочими артефактами;
- если банк уже был — он не перезаписан;
- итог заканчивается одним конкретным следующим шагом (обычно `/bro-remember-it` для дальнейших знаний).

# bro-think-with-me

Используй этот навык для совместного размышления, когда пользователю нужно уменьшить неопределенность, проверить идею или найти лучший следующий шаг.

## ОБЩИЕ ПРАВИЛА

- **ЗАПРЕЩЕНО** менять файлы. Работай ТОЛЬКО в режиме чтения **READONLY**.
- **ОБЯЗАТЕЛЬНО** соблюдай [правила диалога](./references/dialog-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай и **НЕ нарушай** [порядок работы](#порядок-работы)!
- Если ответ пользователя подсказывает лучшую формулировку — обнови формулировку перед переходом дальше.
- Если текущий workflow перестал подходить, переключись на более уместный.

## ПОРЯДОК РАБОТЫ

1. Определи, какая неопределенность у пользователя сейчас главная.
2. Выбери workflow по [правилам выбора workflow](./references/workflow-selection.md).
3. Прочитай только выбранный workflow.
4. Если из контекста разговора нельзя сделать нужные выводы и требуется анализ репозитория — запусти субагента `explorer` по [правилам изучения кода](./references/code-exploration.md).
5. Двигайся маленькими итерациями. Вопрос задавай только по [правилам выбора вопросов](./references/question-selection-rules.md). Иначе назови допущение и продолжай к итогу.
6. После каждого ответа пользователя коротко фиксируй, что именно стало яснее, если это помогает не потерять нить или избежать неверной интерпретации.
7. Если в ходе разговора стало понятно, что выбран не тот workflow, переключись на более уместный и вернись к шагу 3.
8. Заверши разговор итогом, который допустим для текущего workflow.

# specification

Используй этот режим, когда все входные артефакты описывают конечный результат, рамки и критерии — то есть задают, **что** нужно получить, но не предписывают способ реализации.

## Правила

- Прочитай все артефакты задачи полностью и считай их неизменяемыми источниками истины по результату, рамкам и критериям приемки.
- Самостоятельно выбери минимальный полноценный способ реализации, совместимый с существующим кодом.
- Не создавай отдельный plan-артефакт и не изменяй входные артефакты.
- Если имена и содержимое артефактов противоречат друг другу либо результат, рамки или критерии нельзя определить однозначно, остановись и задай человеку один конкретный вопрос.

## Task payload

Передай developer полный контекст текущей единицы работы:

```text
Режим: SPECIFICATION
Артефакты-источники: <пути только для трассировки; они не расширяют назначение>
Цель для пользователя: <требуемый конечный результат>
Рамки: <что входит и не входит>
Текущая единица работы: <связный инкремент>
Критерии приемки: <точные критерии>
Ограничения: <безопасность, совместимость и публичные контракты>
Допущения: <самостоятельно принятые решения, не меняющие результат>
Проверки: <уместные автоматизированные и ручные проверки>
```

Для следующей итерации сохрани относящийся к назначению исходный контекст и добавь невыполненные критерии, ошибки проверок, обязательные замечания ревью и минимальный контекст предыдущей попытки.

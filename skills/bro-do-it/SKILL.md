# bro-do-it

Автономно реализуй согласованную задачу и не завершай работу без доказанного результата.

## Общие правила

- При работе с субагентами соблюдай [правила работы с субагентами](./references/subagents.md);
- Соблюдай [правила автономности и принятия самостоятельных решений](./references/autonomy-and-stop.md);
- Соблюдай [правила проведения ревью после итерации](./references/review-after-iteration.md)
- Не изменяй исходный код самостоятельно, не изменяй входной план или спецификацию;

## Порядок работы

1. Проанализируй всего ли достаточно для реализации в постановке задачи. Уточни информацию при необходимости. Учитывай правила автономности и не задавай вопросов, на которые сам можешь дать ответы.
2. Переходи к первичной реализации:
    - Установи счётчик `Итерация: N/10`, при первом запуске `N = 1`;
    - Вызови субагента `developer` по правилам субагентов с правильно сформированным промптом с полной постановкой задачи;
3. Запусти субагента `regress-checker` для быстрых проверок после реализации. Если есть findings, то переходи к доработкам (шаг 5).
4. Выполни ревью после реализации. Напрямую вызови `/bro-review-code` по всем сделанным изменениям; Соблюдай правила проведения ревью после итерации. Если есть findings, то переходи к доработкам (шаг 5). Иначе этап верификации (шаг 9).
5. Переходи к доработкам реализации:
    - Увеличь N на 1. Если N больше 10, остановись и эскалируй человеку. Иначе выведи `Итерация: N/10`.
    - Вызови субагента `developer` по правилам субагентов с правильно сформированным промптом для конкретных findings;
6. Запусти субагента `regress-checker` для быстрых проверок после реализации. Если есть findings, то вернись к доработкам (шаг 5).
7. Запусти субагента `closer` для проверки закрытия замечаний. В зависимости от результата:
    - При `OPEN` вернись к доработкам (шаг 5) с найденными findings;
    - Иначе перейди к следующему шагу;
8. Запусти повторное ревью после доработок. Напрямую вызови `/bro-review-code` только по изменениям последней итерации доработок. Соблюдай правила проведения ревью после итерации. Если есть findings, то вернись к доработкам (шаг 5).
9. Запусти субагента `verifier` для проверки готовности реализации задачи. В зависимости от результата:
    - При `NEEDS_WORK` вернись к доработкам (шаг 5) с найденными findings;
    - При `BLOCKED` остановись и эскалируй человеку.
    - Иначе перейди к следующему шагу.
10. Сохрани полезные знания в постоянном слое знаний проекта. Напрямую вызови `/bro-remember-it`, передав краткую выжимку итога реализации. Коммит сделай самостоятельно если будут какие-то изменения в банке знаний.
11. Сообщи, что сделано, какие критерии и проверки подтверждены, какие трудности возникли и какие допустимые ограничения остались. Дополнительно напиши как можно проверить результат самому человеку.

### Корректность

#### [medium] HarmonyOS добавляет запрещённую ссылку на браузер

**Где:** `GuestSync.php:68`, `PushToMobileService.php:127`

**Проблема:** Передача `$request` активирует исключение для HarmonyOS, хотя `GuestScenario::canContinueOnBrowser()` возвращает `false`.

**Последствие:** Пользователи Huawei/HarmonyOS увидят запрещённую требованиями ссылку «продолжить в браузере» с `skip_push_mobile=Y`.

**Доказательство:** `isHarmonyOs($request)` независимо создаёт `toBrowserLink`; Vue-компонент отображает ссылку при наличии этого значения. В требованиях предусмотрена только кнопка приложения.

**Исправление:** Исключить переопределение для HarmonyOS в `GuestScenario` либо не передавать `$request` в этом вызове.

**Уверенность:** высокая.

### Тесты

#### [medium] Новый мобильный сценарий не покрыт сквозными тестами

**Где:** `GuestSync.php:43`, `GuestScenario.php:15`, `ConfigFactory.php:23`

**Проблема:** Новый сценарий `/gi/...` и его аналитический контракт не покрыты тестами.

**Последствие:** Могут остаться незамеченными возврат `redirect` вместо `extension`, потеря query-параметров, появление ссылки на браузер и неверные параметры аналитики.

**Доказательство:** Изменение не добавляет тестов; существующие тесты изолированно проверяют только разрешение сценария и построение гостевой deep link.

**Исправление:** Добавить проверки мобильного, настольного и ошибочного сценариев; для мобильного проверить параметры `extension`, query-параметры, отсутствие ссылки на браузер и аналитику.

**Уверенность:** высокая.

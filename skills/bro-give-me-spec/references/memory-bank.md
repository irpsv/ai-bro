# Размещение спецификаций

Корень банка по умолчанию: `memory-bank/` в корне репозитория.

Маркер инициализированного банка: `memory-bank/index.md`.

Перед размещением артефакта **ПРОВЕРЬ** наличие банка. Если `memory-bank/index.md` отсутствует — **СООБЩИ** человеку, что нужна инициализация через `/bro-init-memory-bank`, и **ДОЖДИСЬ** решения.

Спецификации результата **ДОЛЖНЫ** располагаться по пути:

`specs/<feature-id>/spec.md`

Полный путь по умолчанию:

`memory-bank/specs/<feature-id>/spec.md`

`feature-id` — kebab-case: латиница, цифры и дефис. Если фича описана в `features/<feature-id>.md`, идентификатор **ДОЛЖЕН** совпадать.

Если каталог `specs/` отсутствует в существующем memory bank, создай его только после подтверждения полного пути человеком.

Если целевой `spec.md` уже существует, прочитай его, сообщи человеку и получи явное одобрение перед обновлением. Не перезаписывай существующую спецификацию молча.

Корневой `index.md` не должен ссылаться на отдельные файлы в `specs/`.

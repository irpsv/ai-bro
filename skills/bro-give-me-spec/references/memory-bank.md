# Размещение спецификаций

Корень банка по умолчанию: `memory-bank/` в корне репозитория.

Маркер инициализированного банка: `memory-bank/index.md`.

Перед размещением артефакта **ПРОВЕРЬ** наличие банка. Если `memory-bank/index.md` отсутствует — **СООБЩИ** человеку, что нужна инициализация через `/bro-init-memory-bank`, и **ДОЖДИСЬ** решения.

Спецификации результата **ДОЛЖНЫ** располагаться по пути:

`changes/<feature-id>/spec.md`

Полный путь по умолчанию:

`memory-bank/changes/<feature-id>/spec.md`

`<feature-id>` — **всегда** каталог внутри `changes/`. Назначение файла определяет имя `spec.md`. **ЗАПРЕЩЕНО** класть артефакты плоско в `changes/` без каталога `<feature-id>/`.

`feature-id` — kebab-case: латиница, цифры и дефис. Если фича описана в `features/<feature-id>.md`, идентификатор **ДОЛЖЕН** совпадать.

Если каталог `changes/` отсутствует в существующем memory bank, создай его только после подтверждения полного пути человеком.

Перед **первой** записью `spec.md` в текущем запуске **ПОДТВЕРДИ** полный путь у человека. Если целевой файл уже существует, прочитай его, сообщи человеку и получи явное одобрение на обновление. Не перезаписывай существующую спецификацию молча.

После подтверждения пути перезапись того же `spec.md` в рамках циклов ревью и правок текущего запуска разрешена без повторного спроса.

Корневой `index.md` не должен ссылаться на отдельные файлы в `changes/`.

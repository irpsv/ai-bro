# CreatePlan

Workflow для режима планирования harness: спецификация оформляется и размещается тулом `CreatePlan` (или аналогом), без записи файла агентом.

## ПОРЯДОК РАБОТЫ

1. **ВЫЗОВИ** `CreatePlan` (или аналог harness для создания плана). Передай полное содержимое спецификации по шаблону. Если тул принимает заголовок/имя — укажи краткое название задачи. **НЕ ПИШИ** файл спецификации сам — harness оформит и разместит артефакт.

## Quality Control

Перед завершением проверь:

- спецификация передана через `CreatePlan` (или аналог), а не записана агентом в репозиторий;
- в содержимом есть все пять обязательных разделов и нет лишних, кроме допустимого `Принятые решения`;
- нет шагов, этапов и способа реализации;
- каждый изменяемый сценарий покрыт критерием приемки;
- каждый критерий содержит проверяемое доказательство;
- ревью выполнено по правилам (или явно пропущено человеком);
- при `NEEDS_WORK` файл обновлён (путь harness или тул), при `BLOCKED` задан вопрос человеку;
- `/bro-do-it` предложен только после `PASS` или явного пропуска ревью.

# CreatePlan

Workflow для режима планирования harness: спецификация оформляется и размещается тулом `CreatePlan` (или аналогом), без записи файла агентом.

## ОБЩИЕ ПРАВИЛА

- При составлении спецификации **ОБЯЗАТЕЛЬНО** соблюдай структуру разделов из [spec-template.md](../spec-template.md).

## ПОРЯДОК РАБОТЫ

1. **ПРОЧИТАЙ** [spec-template.md](../spec-template.md).
2. **ВЫЗОВИ** `CreatePlan` (или аналог harness для создания плана). Передай полное содержимое спецификации по структуре шаблона. Если тул принимает заголовок/имя — укажи краткое название задачи. **НЕ ПИШИ** файл спецификации сам — harness оформит и разместит артефакт.

## Содержание спецификации

Спецификация в `CreatePlan` **ДОЛЖНА** содержать разделы:

- `Задача и контекст`
- `Целевой результат`
- `Принятые решения`
- `Рамки задачи`
- `Критерии приемки`

Раздел `Принятые решения` **МОЖЕТ** присутствовать только если есть зафиксированные договорённости. Иначе раздел **НЕ** создавай.

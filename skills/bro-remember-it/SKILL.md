# Bro Remember It

Твоя задача — **пополнять** существующий **memory bank**: постоянный слой знаний проекта (контекст, фичи, playbooks).

**НЕ ИНИЦИАЛИЗИРУЙ** банк с нуля — для этого есть скилл инициализации (`/bro-init-memory-bank`).
**НЕ СОЗДАВАЙ** рабочие артефакты в `changes/` — для спецификаций используется `/bro-give-me-spec`, для планов — `/bro-give-me-plan`.

## ОБЩИЕ ПРАВИЛА

- **ОБЯЗАТЕЛЬНО** соблюдай [правила диалога](./references/dialog-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай [структуру memory bank](./references/memory-bank-structure.md) и [правила содержимого](./references/content-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай и **НЕ нарушай** [порядок работы](#порядок-работы)!
- Сначала самостоятельно собери контекст из репозитория и существующего банка.
- Не спрашивай то, что можно установить с высокой уверенностью.
- Помечай выведенное как выведенное, пока пользователь его не подтвердит.

## ОГРАНИЧЕНИЯ / STOP

- **ЗАПРЕЩЕНО** создавать memory bank с нуля и запускать init-скрипты.
- **ЗАПРЕЩЕНО** создавать или изменять файлы в `changes/`.
- **ЗАПРЕЩЕНО** ссылаться из `features/` на `changes/`.
- **ЗАПРЕЩЕНО** создавать подкаталоги в `features/` — одна фича, один файл.
- **ЗАПРЕЩЕНО** придумывать факты о проекте.

## ПОРЯДОК РАБОТЫ

1. **ОПРЕДЕЛИ** путь к memory bank (по умолчанию `memory-bank/` в корне репозитория).
2. **ПРОВЕРЬ**, что `memory-bank/index.md` существует. Если нет — **ОСТАНОВИСЬ**, сообщи что банк не инициализирован, и **ПРЕДЛОЖИ** `/bro-init-memory-bank`.
3. **ПРОЧИТАЙ** [replenish](./workflows/replenish.md) и **СОБЛЮДАЙ** его инструкции.
4. После завершения **ПОКАЖИ** человеку итог: что изменено, что требует уточнения.

## Quality Control

Перед завершением проверь:

- структура не нарушена: обязательные `index.md`, `project/`, `features/`, `playbooks/`, `changes/` на месте;
- корневой `index.md` ссылается только на `project/*.md`, `features/index.md`, `playbooks/index.md`;
- фичи — плоские файлы `features/<feature-id>.md`, реестр в `features/index.md`;
- playbooks — плоские файлы `playbooks/<slug>.md`, реестр в `playbooks/index.md`;
- нет дублей и выдуманных фактов;
- `changes/` не затронут.

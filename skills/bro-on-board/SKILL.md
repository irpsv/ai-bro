# Bro On Board

Твоя задача — познакомить человека с набором скиллов ai-bro: карта команд, типовой флоу и понятный следующий шаг.

**НЕ СОЗДАВАЙ** артефакты планирования в `plans/` — для планов есть скилл планирования (`/bro-give-me-plan`).
**НЕ СОЗДАВАЙ** спецификации результата в `specs/` — для них используется `/bro-give-me-spec`.

## ОБЩИЕ ПРАВИЛА

- **ОБЯЗАТЕЛЬНО** соблюдай [правила диалога](./references/dialog-rules.md)!
- **ОБЯЗАТЕЛЬНО** соблюдай и **НЕ нарушай** [порядок работы](#порядок-работы)!
- Сначала самостоятельно собери контекст: есть ли уже memory bank, что за проект.
- Не спрашивай то, что можно установить с высокой уверенностью.
- Держи онбординг коротким: карта скиллов и следующий шаг, без полного разбора всех workflow.

## ОГРАНИЧЕНИЯ / STOP

- **ЗАПРЕЩЕНО** создавать или изменять файлы в `plans/`.
- **ЗАПРЕЩЕНО** создавать или изменять файлы в `specs/`.
- **ЗАПРЕЩЕНО** придумывать факты о проекте.
- **ЗАПРЕЩЕНО** уходить в реализацию задачи пользователя во время онбординга.

## ПОРЯДОК РАБОТЫ

1. **ПРОЧИТАЙ** [tour](./workflows/tour.md) и **СОБЛЮДАЙ** его инструкции.
2. После завершения **ПОКАЖИ** человеку итог и один понятный следующий шаг.

## Quality Control

Перед завершением проверь:

- человек понимает, какой скилл когда вызывать;
- статус memory bank ясен;
- если банка нет — человек знает про `/bro-init-memory-bank`;
- если банк есть — человек знает про `/bro-remember-it` для пополнения;
- итог заканчивается одним конкретным следующим шагом.

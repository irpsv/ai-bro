# Поиск memory bank

Анализ репозитория в поисках существующего банка памяти

**ПРОВЕРЬ** memory bank:
   - готовый банк — только маркер `memory-bank/index.md`;
   - дополнительно быстро посмотри похожие следы без маркера: каталог `memory-bank/` без `index.md`, `memory_bank/`, `.memory-bank/`, `docs/memory-bank/`.

**Маркер есть** — банк готов. Похожие следы не обсуждай.

- Скажи, что memory bank есть — красавчик!
- Этот чат оставь. Попроси открыть новый и начать с `/bro-think-with-me` плюс задача.

**Маркера нет** — банка нет. Если нашёл похожие следы, назови их и явно скажи, что это ещё не банк.

- Кратко объясни, зачем банк: постоянный слой знаний о проекте, чтобы не объяснять одно и то же в каждом чате.
- **ПРЕДЛОЖИ** собрать его сейчас. Один вопрос, варианты:
  1) Да, давай соберём
  2) Пока нет
- После «да» **СРАЗУ** вызови `/bro-init-memory-bank` и передай задачу создать банк для этого проекта. Init сам спросит путь — это ожидаемо.
- После завершения init сделай тот же handoff, что при готовом банке: красавчик, новый чат, `/bro-think-with-me`.
- Если человек отказался — не запускай init. Скажи, что банк можно собрать позже командой `/bro-init-memory-bank`, а задачу всё равно лучше писать в новом чате.

## Критерии завершения

- Человек понял, что это за набор, как им пользоваться и куда писать задачу.
- По карте видно, какой скилл когда вызывать — на примерах, не списком названий.
- Статус memory bank ясен: есть маркер или нет.
- Если банка нет — либо init уже вызван после согласия, либо человек отказался и знает про `/bro-init-memory-bank`.
- Если банк готов или только что собран — финал это рекомендация нового чата с `/bro-think-with-me`.

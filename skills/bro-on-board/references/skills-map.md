# Карта скиллов ai-bro

Краткий справочник для онбординга. Не подменяй им чтение workflow других скиллов.

| Этап | Команда | Зачем |
|---|---|---|
| Думаем | `/bro-think-with-me` | Прояснить мысль, найти причину проблемы или выбрать подход |
| Специфицируем | `/bro-give-me-spec` | Зафиксировать результат, приемку и рамки без способа реализации |
| Планируем | `/bro-give-me-plan` | Составить план реализации со шагами (в чате или файлом) |
| Делаем | `/bro-do-it` | Автономно реализовать и повторять проверки с ревью до приемки |
| Ревьюим код | `/bro-review-code` | Независимо проверить изменения кода без исправлений |
| Инициализация банка | `/bro-init-memory-bank` | Создать memory bank с нуля |
| Помним | `/bro-remember-it` | Пополнить существующий memory bank |
| Онбординг | `/bro-on-board` | Знакомство с набором скиллов |

## Типовой флоу

1. Прояснить задачу или найти причину бага — `/bro-think-with-me`.
2. Зафиксировать желаемый результат без способа реализации — `/bro-give-me-spec` — либо составить план реализации — `/bro-give-me-plan`.
3. Реализовать по спецификации, плану или прямо из диалога — `/bro-do-it`.
4. При необходимости отдельно проверить текущий код — `/bro-review-code`.
5. Запомнить устойчивые знания — `/bro-remember-it`.

## Memory bank

Постоянный слой знаний проекта: `project/`, `features/`, `playbooks/`.  
Раздел `specs/` — временные спецификации результата, их создаёт `/bro-give-me-spec`.
Раздел `plans/` — временные артефакты планирования, их создаёт скилл планирования.

- Банка ещё нет → инициализация через `/bro-init-memory-bank`.
- Банк уже есть → пополнение через `/bro-remember-it`.

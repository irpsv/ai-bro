Этот чат — знакомство. Задачу лучше писать в новом: можно команду из набора, можно просто своими словами.

Обычный путь такой. Сначала разбираемся, что происходит: мысль сырая, идея спорная или что-то сломалось и непонятно почему. Для этого `/bro-think-with-me` — он не пишет код, а помогает прояснить, проверить логику или найти причину. Например: `/bro-think-with-me после деплоя периодически падает создание заказа, помоги найти причину`.

Когда уже ясно, *что* должно получиться, но способ реализации оставляешь агенту — `/bro-give-me-spec`. Он фиксирует результат, приёмку и рамки, без шагов и архитектуры. Например: `/bro-give-me-spec зафиксируй спецификацию результата для rate limiting публичного API`.

Если нужен именно план «что делать по шагам» — `/bro-give-me-plan`. Небольшой план можно оставить в чате, крупнее — файлом. Например: `/bro-give-me-plan нужно составить план для добавления rate limiting на публичный API`.

Когда пора кодить — `/bro-do-it`. Он берёт спецификацию, план или задачу из диалога и доводит до результата с проверками и ревью. Например: `/bro-do-it поправь текст ошибки в форме входа и добавь тест на этот сценарий`.

Если изменения уже есть и нужно только независимо проверить, без правок — `/bro-review-code`. Например: `/bro-review-code проверь текущую ветку относительно main`.

Чтобы не рассказывать проект заново в каждом чате, есть memory bank: постоянные знания о проекте. С нуля его заводит `/bro-init-memory-bank`, а пополняет уже существующий — `/bro-remember-it`. Например: `/bro-init-memory-bank заведи memory bank для этого проекта` или `/bro-remember-it добавь в memory bank описание фичи rate limiting`.

Команды заучивать не обязательно. В новом чате достаточно описать, что нужно — и пойти по этому пути: подумать, при необходимости зафиксировать результат или план, сделать, проверить, запомнить.
